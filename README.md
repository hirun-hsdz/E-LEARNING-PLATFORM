# E-Learning Platform

An intermediate-level, frontend-only group project built with HTML, CSS and JavaScript.

## Team
- Member 1: Team lead, GitHub integration and shared layout
- Member 2: Home page and course catalogue
- Member 3: Login and registration UI
- Member 4: Course details and lesson viewer
- Member 5: Quiz and assessment
- Member 6: Student dashboard and progress
- Member 7: Profile and saved courses
- Member 8: UI/UX, responsive testing and quality checks

## Run
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Notes
- This folder is a starter structure. Feature sections are placeholders for the team to implement.
- Use sample/demo data and LocalStorage for a frontend prototype.
- LocalStorage is browser-local, not a shared database.
- Do not store real passwords or sensitive personal information.
- Use separate Git branches and pull requests for each feature.
